## Függvény és pont

Egy függvény minden $x$-hez **pontosan egy** $y$-t rendel. A grafikon pontjai $(x, f(x))$ alakúak: például $f(x) = x^2$ esetén $x = 2$-höz a $(2, 4)$ pont tartozik.

## Egyenes két ponton át

Két különböző $x$-koordinátájú ponton pontosan egy egyenes megy át. Az egyenes egyenlete $f(x) = ax + b$, ahol $a$ a **meredekség**, $b$ az **$y$-tengelymetszet**.

<Pelda cim="a gyakorlatról: A(2, 3), B(8, 5)">
Mindkét pont koordinátáit behelyettesítjük:
$$
3 = 2a + b, \qquad 5 = 8a + b.
$$
A két egyenletet kivonva $b$ kiesik: $3 - 5 = 2a - 8a$, azaz $-2 = -6a$, tehát $a = \frac{1}{3}$.

Visszahelyettesítve: $3 = \frac{2}{3} + b$, így $b = \frac{7}{3}$.

$$
f(x) = \frac{1}{3}x + \frac{7}{3}
$$
GeoGebrában ugyanezt adja a `FitPoly(A, B)` parancs.
</Pelda>

## Több pont, magasabb fokszám

$n$ ponton (különböző $x$-ekkel) pontosan egy legfeljebb $(n-1)$-edfokú polinom megy át:
- 2 pont → egyenes ($ax + b$),
- 3 pont → parabola ($ax^2 + bx + c$),
- 4 pont → harmadfokú, és így tovább.

Minden pont egy egyenletet ad az ismeretlen együtthatókra, $n$ pont $n$ egyenletet $n$ ismeretlenre.

<Pelda cim="parabola három ponton át">
$A(0, 1)$, $B(1, 0)$, $C(2, 3)$, $f(x) = ax^2 + bx + c$.
- $A$: $1 = c$
- $B$: $0 = a + b + c$, tehát $a + b = -1$
- $C$: $3 = 4a + 2b + c$, tehát $4a + 2b = 2$, azaz $2a + b = 1$

A két utolsót kivonva: $a = 2$, majd $b = -3$. Tehát $f(x) = 2x^2 - 3x + 1$. Ellenőrzés: $f(2) = 8 - 6 + 1 = 3$. ✓
</Pelda>

<Figyelem>
Ha két pontnak ugyanaz az $x$-koordinátája (de más az $y$), egyetlen függvény sem mehet át mindkettőn, hiszen egy $x$-hez csak egy $y$ tartozhat. Az egyenletrendszer ilyenkor ellentmondásos.
</Figyelem>

<Megjegyzes>
Sok pontra illesztett magas fokú polinom a pontok között gyakran nagyon „hullámzik”. Próbáld ki: tegyél 5 pontot majdnem egy egyenesbe, és húzd el kicsit az egyiket.
</Megjegyzes>

<Feladat>
Melyik parabola megy át a $(-1, 4)$, $(0, 1)$, $(1, 0)$ pontokon?

<Megoldas>
$c = 1$ (a második pontból). $4 = a - b + 1$ és $0 = a + b + 1$, tehát $a - b = 3$ és $a + b = -1$. Összeadva $2a = 2$, $a = 1$, $b = -2$. Így $f(x) = x^2 - 2x + 1 = (x - 1)^2$. Az $(1, 0)$ pont a csúcs.
</Megoldas>
</Feladat>
