<Kartya cim="Hány pont, hányadfokú?">
$n$ ponton (különböző $x$-ekkel) pontosan egy legfeljebb $(n-1)$-edfokú polinom megy át:

| pontok | polinom | ismeretlenek |
|---|---|---|
| 2 | $ax + b$ (egyenes) | 2 |
| 3 | $ax^2 + bx + c$ (parabola) | 3 |
| 4 | $ax^3 + bx^2 + cx + d$ | 4 |

Minden pont **egy egyenletet** ad, és annyi egyenlet kell, ahány ismeretlen együttható van.

Legfeljebb hányadfokú polinom illeszthető 5 pontra?
</SzamValasz>
</Kartya>

<Kartya cim="Parabola három ponton át">
$A(0, 1)$, $B(1, 0)$, $C(2, 3)$, és keressük: $f(x) = ax^2 + bx + c$.

Helyettesítsd be az $A$ pontot: $f(0) = a \cdot 0 + b \cdot 0 + c = 1$.

<SzamValasz helyes="1" mezok={["c ="]} magyarazat="Az x = 0 pont mindig rögtön megadja c-t.">
Mennyi $c$?
</SzamValasz>
</Kartya>

<Kartya cim="A másik két pont">
$B(1, 0)$: $\ a + b + c = 0$, azaz $a + b = -1$.

$C(2, 3)$: $\ 4a + 2b + c = 3$, azaz $4a + 2b = 2$, osztva 2-vel: $2a + b = 1$.

<SzamValasz helyes={["2", "-3"]} mezok={["a =", "b ="]} tipp="Vond ki az a + b = −1 egyenletet a 2a + b = 1-ből." magyarazat="(2a + b) − (a + b) = 1 − (−1), tehát a = 2, és b = −1 − 2 = −3.">
Oldd meg: $a + b = -1$, $2a + b = 1$.
</SzamValasz>

<SzamValasz helyes="2x^2 - 3x + 1" valtozok={["x"]} mezok={["f(x) ="]} magyarazat="Ellenőrzés: f(2) = 8 − 6 + 1 = 3. ✓">
Tehát mi a parabola egyenlete?
</SzamValasz>
</Kartya>

<Kartya cim="Röviden">
<Osszefoglalo>
- $n$ pont (különböző $x$-ek) → pontosan egy, legfeljebb $(n-1)$-edfokú polinom.
- Minden pont egy egyenlet az együtthatókra; az $x = 0$ pont rögtön megadja a konstans tagot.
- GeoGebra: `FitPoly({A, B, C}, 2)`.
- Egyforma $x$, különböző $y$: nincs megoldás.
</Osszefoglalo>
